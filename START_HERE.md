# Start here

Ability lifecycle code from VZN Framework, my larger Roblox ECS framework. Its custom ECS engine is inspired by [jecs](https://github.com/Ukendio/jecs).

1. [Runner.luau](Runner.luau) — start, hold, release, cancellation, and cleanup.
2. [Types.luau](Types.luau) — the shared types used by the runner.
3. [ChargeAbility.luau](ChargeAbility.luau) — a charge-ability usage example.
